# MindBoard

一个在自己电脑上运行的思维导图 + 头脑风暴白板。没有账号、没有云端、没有构建步骤：每个画板存成一个普通文件，放进 Google Drive 之类的同步文件夹就能多设备使用。

主要为两类事情设计：**视频策划**（选题 → 钩子 → 脚本 → 分镜 → 发布）和**文献综述**（按主题归类论文卡片，标注引用 / 反驳关系，最后导出成 Markdown 大纲去写作）。

## 能做什么

- **无限画布**：左键在空白处拖动框选，按住鼠标右键拖动平移，滚轮缩放。
- **思维导图**：`Tab` 加子节点、`Enter` 加同级节点，分支自动排版、自动配色，可折叠。
- **自由白板**：便签、卡片、图片随手摆；把节点拖到另一个节点上就挂成它的子节点，拖到空白处就独立出来。
- **卡片**：第一行自动当标题，`#标签`、`**加粗**`、网址自动识别，适合做文献卡和分镜卡。
- **连线**：选中节点后拖右上角的小圆点到另一个节点，双击连线可以加文字（比如「反驳」「扩展」）。
- **模板**：视频策划、文献综述、头脑风暴、空白。
- **多画板**：左上角 ☰ 切换 / 新建 / 删除。
- **导入**：粘贴 Markdown 大纲或缩进列表直接变成导图；粘贴 / 拖入图片。
- **导出**：PNG 图片、Markdown 大纲、JSON 备份。
- 撤销 / 重做、搜索、深色模式。

## 在本机运行

需要 Python 3（只用标准库，不用装任何依赖）。

Windows 双击 `start.bat`，macOS / Linux 运行 `./start.sh`，或者：

```bash
python server.py
```

浏览器会自动打开 <http://localhost:5178>。服务只监听本机（127.0.0.1），不对外网开放。

## 多设备同步（Google Drive / OneDrive / iCloud）

每个画板就是一个 `画板名-xxxx.mindboard.json` 文件。把保存文件夹指到网盘的同步目录里，其他设备上的 MindBoard 也指到同一个文件夹，就同步了。两种设置方式：

- 在页面里：左上角 ☰ →「更改保存文件夹…」，粘贴路径，例如 `H:\我的云端硬盘\MindBoard`。设置记在 `mindboard.config.json` 里，下次启动自动沿用。
- 启动时指定：

```bash
python server.py --data "H:/我的云端硬盘/MindBoard"
```

几点说明：

- 网盘把别的设备的修改同步下来之后，页面在切回窗口时（以及每隔几秒）会自动载入新版本。
- 如果两台设备同时改了同一个画板，页面会自动合并两边的改动；同一个节点两边都改了，以后保存的一方为准。
- 平移 / 缩放位置只记在本机，不写进文件，所以单纯浏览不会触发网盘上传。
- 删除画板不会真删文件，而是挪进保存文件夹下的 `.trash`。
- 图片内嵌在画板文件里（自动压缩到最长边 1600px）。

不想起服务也可以直接双击 `index.html`，这时是纯浏览器模式：数据只存在这个浏览器的 IndexedDB 里，可以用「文件 → 导出 / 导入 JSON 备份」手动搬运。

PNG 导出会从 jsDelivr 按需加载 [html-to-image](https://github.com/bubkoo/html-to-image)，这一步需要联网；其余功能全部离线可用。

## 和 AI 一起读文献

思路是两步：**读的时候只管记，读完再整理**。Claude 通过一组工具直接读写画板文件，当速记员和讨论对象。

### 收件箱速记

页面底部有一条速记条。按 `N` 跳过去，写一句话回车，就进了画板上的「📥 收件箱」，不用想它该挂在哪。想用语音，光标在速记条里时按 `Win`+`H`（Windows 自带听写）。

### 让 Claude 读写画板

`mcp_server.py` 是一个 MCP 服务（只用 Python 标准库），提供这些工具：列出画板、把画板读成带 id 的大纲、速记进收件箱、在节点下加节点或卡片、挪动节点、改文字、连线、删除。

- **在这个文件夹里开 Claude Code**：仓库自带 `.mcp.json`，第一次会问你是否启用 `mindboard`，同意即可。
- **在任何文件夹里都能用**（把路径换成你 clone 的位置）：

```bash
claude mcp add --scope user mindboard -- python G:/Git/mindboard/mcp_server.py
```

- **Claude 桌面版的普通聊天**：在 `claude_desktop_config.json` 的 `mcpServers` 里加一项，`command` 填 `python`，`args` 填 `mcp_server.py` 的完整路径。

接好之后，把论文 PDF 给 Claude，然后直接说话就行，比如：

- 「开一个画板叫 XX 综述，把这篇论文的骨架列出来」
- 「第 5 页说样本只有 32 人，记一下」
- 「他们的对照组怎么选的？」
- 「整理一下收件箱」

MindBoard 开着的时候，Claude 写入的内容几秒内就会出现在画板上。服务没开也能写，下次打开就能看到。

### AI 写的内容要你确认

Claude 新增、修改、挪动的节点都带虚线边框和 `AI` 角标。选中后点「✓ 确认」才算数，直接删除就是拒绝，亲手改过文字也算确认。顶部的「AI 待确认 N」可以一次选中全部，旁边有「全部确认」。你自己说的、被原话记进收件箱的速记不带这个标记。

你在画板上编辑的同时 Claude 也在写，不会互相覆盖：页面会把两边的改动合并。只有同一个节点两边都改了的时候，以你这边为准。

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 添加子节点 / 同级节点 | `Tab` / `Enter` |
| 编辑 | `F2`、`空格` 或双击 |
| 框选 | 左键在空白处拖动；`Shift` 追加 |
| 平移画布 | 按住鼠标右键（或中键）拖动 |
| 完成编辑 | 主题：`Enter`（`Shift+Enter` 换行）；便签 / 卡片：`Ctrl+Enter` 或 `Esc` |
| 折叠 / 展开 | `/` |
| 调整同级顺序 | `Alt+↑` / `Alt+↓` |
| 在节点间移动 | 方向键 |
| 删除 | `Delete` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 复制 / 粘贴 / 原地复制 | `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| 搜索 | `Ctrl+F`，回车跳到下一个结果 |
| 适应屏幕 | `1` |
| 速记到收件箱 | `N`，写完回车 |
| 只移动不挂接 | 按住 `Alt` 拖动 |
