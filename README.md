# MindBoard

一个在自己电脑上运行的思维导图 + 头脑风暴白板。没有账号、没有云端、没有构建步骤：每个画板存成一个普通文件，放进 Google Drive 之类的同步文件夹就能多设备使用。

主要为两类事情设计：**视频策划**（选题 → 钩子 → 脚本 → 分镜 → 发布）和**文献综述**（按主题归类论文卡片，标注引用 / 反驳关系，最后导出成 Markdown 大纲去写作）。

## 能做什么

- **无限画布**：拖空白处平移，滚轮缩放，`Shift`+拖动框选。
- **思维导图**：`Tab` 加子节点、`Enter` 加同级节点，分支自动排版、自动配色，可折叠。
- **自由白板**：便签、卡片、图片随手摆；把节点拖到另一个节点上就挂成它的子节点，拖到空白处就独立出来。
- **卡片**：第一行自动当标题，`#标签`、`**加粗**`、网址自动识别，适合做文献卡和分镜卡。
- **连线**：选中节点后拖右上角的小圆点到另一个节点，双击连线可以加文字（比如「反驳」「扩展」）。
- **模板**：视频策划、文献综述、头脑风暴、空白。
- **多画板**：左上角 ☰ 切换 / 新建 / 删除。
- **导入**：粘贴 Markdown 大纲或缩进列表直接变成导图；粘贴 / 拖入图片。
- **导出**：PNG 图片、Markdown 大纲、JSON 备份。
- 撤销 / 重做、搜索、深色模式。

## 在本机运行

需要 Python 3（只用标准库，不用装任何依赖）。

Windows 双击 `start.bat`，macOS / Linux 运行 `./start.sh`，或者：

```bash
python server.py
```

浏览器会自动打开 <http://localhost:5178>。服务只监听本机（127.0.0.1），不对外网开放。

## 多设备同步（Google Drive / OneDrive / iCloud）

每个画板就是一个 `画板名-xxxx.mindboard.json` 文件。把保存文件夹指到网盘的同步目录里，其他设备上的 MindBoard 也指到同一个文件夹，就同步了。两种设置方式：

- 在页面里：左上角 ☰ →「更改保存文件夹…」，粘贴路径，例如 `H:\我的云端硬盘\MindBoard`。设置记在 `mindboard.config.json` 里，下次启动自动沿用。
- 启动时指定：

```bash
python server.py --data "H:/我的云端硬盘/MindBoard"
```

几点说明：

- 网盘把别的设备的修改同步下来之后，页面在切回窗口时（以及每 15 秒）会自动载入新版本。
- 如果两台设备同时改了同一个画板，后保存的一方不会覆盖对方，而是另存为「画板名（冲突副本）」，由你手动合并。
- 平移 / 缩放位置只记在本机，不写进文件，所以单纯浏览不会触发网盘上传。
- 删除画板不会真删文件，而是挪进保存文件夹下的 `.trash`。
- 图片内嵌在画板文件里（自动压缩到最长边 1600px）。

不想起服务也可以直接双击 `index.html`，这时是纯浏览器模式：数据只存在这个浏览器的 IndexedDB 里，可以用「文件 → 导出 / 导入 JSON 备份」手动搬运。

PNG 导出会从 jsDelivr 按需加载 [html-to-image](https://github.com/bubkoo/html-to-image)，这一步需要联网；其余功能全部离线可用。

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 添加子节点 / 同级节点 | `Tab` / `Enter` |
| 编辑 | `F2`、`空格` 或双击 |
| 完成编辑 | 主题：`Enter`（`Shift+Enter` 换行）；便签 / 卡片：`Ctrl+Enter` 或 `Esc` |
| 折叠 / 展开 | `/` |
| 调整同级顺序 | `Alt+↑` / `Alt+↓` |
| 在节点间移动 | 方向键 |
| 删除 | `Delete` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 复制 / 粘贴 / 原地复制 | `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| 搜索 | `Ctrl+F`，回车跳到下一个结果 |
| 适应屏幕 | `1` |
| 只移动不挂接 | 按住 `Alt` 拖动 |
